= @metadatastician/marid-client (planned)

Framework-independent AffineScript client (JaffaScript face, compiled
to typed WebAssembly): cancellation, errors, live subscriptions,
reconnect/resynchronization (`PROJECT_BRIEF.md` §5).

Compatibility requirements: no `window`/`document` access merely from
importing the SDK; request-scoped credentials and caches for SSR use;
reconnection detects missed updates and resynchronizes; older browser
bundles stay compatible during rolling server deployments.

Status: Gate 0 skeleton. Implemented at Gate 4.
