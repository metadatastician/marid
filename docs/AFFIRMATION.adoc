== What this is, and how it works

Marid is a Julia-first framework for web applications, APIs and reactive
dashboards. It is a monorepo of 13 Julia packages under `packages/`, a runnable
HTTP/JSON example under `examples/http_json/`, and Bun-tested web clients under
`web/`. This file reports what the repo's own checks printed when run against
one commit on 2026-10-07. It supersedes the 2026-09-19 affirmation, now at
`docs/affirmations/AFFIRMATION-2026-09-19.adoc`.

=== The honest nuance you must not lose

* *One Julia version.* Only 1.10.10 was run. CI's matrix also names 1.11, and
  the machine default here is 1.12.6. Nothing is claimed for either.
* *`just test` was not the route.* `just test` runs `./scripts/marid check`,
  which drives the package tests through an inline `python3 -c` script, and its
  package list names `ArangoDB` where the directory is `MaridArango`. The
  per-package commands above were run directly instead, as the CI workflow
  runs them. The Python route was not exercised.
* *`just validate` checks template shape*, not Marid behaviour.
* *The e2e suite checks nothing.* `bash tests/e2e.sh` exited 0 with PASS=1,
  but the one "pass" printed "Self-skipping: archetypes/ not found". A skip is
  counted as a pass.

== Reproduce it yourself

[source,bash]
----
git clone https://github.com/metadatastician/marid && cd marid
git checkout fd139f763a306a7e2eca60d96ea1a1a9f77c1e71
for p in MaridIR MaridCodec MaridOpenAPI MaridRPC MaridGraphQL \
         MaridTransport MaridCore MaridArango MaridStorage MaridControl \
         MaridLive MaridCRDT MaridRaft; do
  julia --startup-file=no scripts/bootstrap.jl packages/$p
  julia --startup-file=no --project=packages/$p packages/$p/test/runtests.jl
done
# expect: every suite passes; 385 assertions in all (Julia 1.10.10)
julia --startup-file=no scripts/check-julia-compat.jl
julia --startup-file=no scripts/check-packages-precompile.jl
# expect: checked 13 package(s); 0 failing (both)
julia --startup-file=no scripts/bootstrap.jl examples/http_json
julia --startup-file=no --project=examples/http_json \
  examples/http_json/test/runtests.jl
# expect: 30/30, possibly only on a second, warm run
(cd web && bun install --frozen-lockfile && bun test)
# expect: 13 pass, 0 fail
just validate
# expect: All validations passed!
bash scripts/check-adoc-renders.sh .
# expect: PASS: all 210 tracked .adoc file(s) render clean
----
