== 2. Security and Failure Behavior

1. **RFC 9457 Problem Details Error Hygiene**:
   * All application exceptions map deterministically into standard Problem Details payloads.
   * Internal Julia stack traces and raw system memory dumps are suppressed in client responses.
2. **Backpressure & Denial of Service Protection**:
   * Streaming channels (`Stream{T}`) enforce strict capacity limits (defaulting to 32 items).
   * Producer coroutines block cooperatively when buffers fill, preventing memory exhaustion under slow consumers.
3. **Optimistic Concurrency & Revision Checking**:
   * All mutating document and edge operations in `ArangoDB.jl` support conditional `_rev` matching.
   * Revision mismatches reliably yield HTTP 412 / Error 1200, eliminating lost updates in concurrent environments.
4. **Subscription Lifecycle & Memory Leaks**:
   * `@marid/react` and `@marid/vue` bindings guarantee unmount cancellation via `useEffect` and `onUnmounted` hooks.
   * Network connections and timers are aborted via `AbortController`, preventing orphan background tasks.

== 6. Package Registration & Polyrepo Migration Roadmap

When the user initiates the polyrepo split, the monorepo packages will be extracted into independent repositories under the `hyperpolymath` organization using `git subtree` to preserve commit history.

=== Git Subtree Extraction Recipe

Each package can be cleanly extracted into its dedicated repository using:
```bash
git subtree split -P packages/MaridIR -b release/MaridIR
git push git@github.com:hyperpolymath/MaridIR.jl.git release/MaridIR:main
```
